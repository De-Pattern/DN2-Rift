# RIFT

**A second firmware for the Elektron Digitone II, built around new engines with no compromises.**

RIFT is separate from the DN2 mk2 mod. It has no Machinedrum or Monomachine machines. It
starts with one engine, **FASCIA**: a physical/spectral percussion and tuned-body machine
(two exciters into two coupled modal bodies, TZFM, ring and frequency shift, a spectral
morph, an LPG). More engines and effects follow, each added only when it fits and is right.

> **Status: in development. There is no release to flash yet.** Nothing is released until
> it has passed the full safety gate (`scripts/ship_gate.py` printing `CLEARED TO FLASH`).
>
> **Not made or supported by Elektron.** Unofficial firmware, built from your own copy of
> Elektron's OS; no Elektron firmware is in this repository. You flash it at your own risk.
